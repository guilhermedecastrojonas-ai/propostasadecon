Propostas Adecon
Painel interno da Adecon – Empresa Júnior de Consultoria Empresarial (UEM) para gerar a Proposta Formalizada a partir do escopo de cada projeto.

Como usar
No Google Docs, baixe o escopo em Arquivo › Fazer download › Microsoft Word (.docx).
Abra o painel, clique em Nova proposta e arraste o arquivo.
Complete cliente, logo (PNG sem fundo), contexto, objetivo e valor. A prévia ao lado se atualiza enquanto você digita.
Baixe a proposta em HTML, com os botões interativos, ou em PDF.
Onde ficam os dados
Nada é enviado a um servidor. As propostas ficam salvas no navegador de quem usa.
Use Exportar histórico para guardar uma cópia e Importar para levar as propostas a outro computador.
Limpar os dados do navegador apaga o histórico. Exporte com frequência.
Atualizar o painel
O painel inteiro está em um único arquivo, index.html. Para publicar uma versão nova, substitua esse arquivo no repositório. O GitHub Pages atualiza o link em cerca de um minuto.
